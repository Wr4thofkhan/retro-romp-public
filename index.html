No permission requests — for friends

Friends do not have to ask permission to download every game, as long as Saud shares the Drive folder as “Anyone with the link, Viewer”. Then friends can download any game with no Google account, no login, and no permission request. If the folder is left restricted / only specific people, every friend will hit a “Request access” prompt per file — so this setting is what makes it work. Downloads from Vimm’s Lair need no Drive permission at all.

For Saud, the setup is: open Google Drive, right-click the “Games and ROMS” folder, choose Share > Share; under General access, change it to “Anyone with the link” and set the role to “Viewer”; click Copy link / Done. That is the whole setup — no per-file sharing, no per-game permission requests.

Set up a ROMS folder

one folder on your device, all your games in it

How to make it

1. Open your Files app. On Android, open Files, go to Internal storage, tap the 3 dots or +, then New folder, and name it ROMS. On iPhone, open Files, go to On My iPhone, tap the 3 dots, then New Folder, and name it ROMS.

2. Every time you download a game, save it into that ROMS folder, so all your games live in one place.

3. Disc games are the exception: all the files for one disc game must stay together in their own folder inside ROMS, for example ROMS / Marvel vs. Capcom 2, with the .cue file and all its track files (.bin / .raw) in that one folder. Load the .cue file, not a single track file.

4. Back on this site, go to On This Device, tap Load the downloaded file, open your ROMS folder, and pick the game file. It is saved in your browser on this device only, and the green Play button appears.

You do not need a ROMS folder to play a game, it just keeps downloads tidy and keeps disc-game tracks together. A normal cartridge game is one file, and that one file is all you need.

Please read this first

Vimm’s Lair blocks automated fetches with a Cloudflare check, so this site never downloads from Vimm’s itself. You download the ROM from Vimm’s yourself (tap the game’s Vimm’s link, it opens in a new tab), then come back and use “Add the ROM” — the Load the downloaded file button above — to play it. The catalogs below are a bundled selection, not the whole vault. The full SNES vault on Vimm’s holds over 4,100 games (verified: 4,147 known media, No-Intro dat 2026-11-20). Use Search all of Vimm’s to reach the rest.

Honest limits

  • RetroAchievements is NOT implemented. EmulatorJS does not implement it, so we do not pretend it works.
  • Saves are stored locally on the device, not synced to Google Drive.
  • No Dreamcast. Dreamcast games are played in the separate Flycast app, not here.
  • Actual gameplay needs a real ROM file you supply — downloaded from Drive or Vimm’s and loaded on your device.
  • Neo Geo games need the neogeo.zip BIOS file alongside them. PC Engine / SuperGrafx cartridge games need no BIOS.
  • N64: games get up to 120 seconds to start before timing out. If a game stays black, you will see a clear error and a way back — never a silent black screen. X-Men vs. Street Fighter 64 black-screens on mupen64plus_next, so it defaults to parallel_n64.

Cover art: Libretro Thumbnails on GitHub first; if a cover is missing, the card shows a styled letter tile with the game’s initials instead of a broken image. No ScreenScraper, IGDB, SteamGridDB, MobyGames, The Cover Project, or VGBoxArt.
